# Nicolas Cole Writing Structures

## Introduction Rhythms

### 1/3/1 (Most Common - Short & Punchy)

**Formula**:
```
Single sentence opener.

3-sentence paragraph (clarify, reinforce, round out).

Single sentence conclusion.
```

**When to use**: Quick hooks, fast-paced content, technical explanations

**Example**:
```
Life is all about perspective.

The exact same situation can be perceived differently by two people. One might see loss—the other, opportunity. Which means the first step to becoming who you want to be means accepting that your view might not be the whole picture.

Here are some mental shifts that can help you see things differently.
```

### 1/5/1 (More Context)

**Formula**:
```
Single sentence opener.

5-sentence paragraph (more descriptive, builds context).

Single sentence conclusion.
```

**When to use**: Need more setup, technical background, longer stories

**Example (from Cole)**:
```
The dream before becoming an entrepreneur is work-life balance.

I remember my 9-5 commute—an hour each way. Sometimes I'd work late, not leaving until 8 p.m. I'd finally get home, throw my backpack on my bed, and realize the day was over. Just enough time to cook dinner and write before passing out. Then repeat.

Becoming an entrepreneur, I thought, would give me more time for my passions.
```

### 1/4/1/1 (Double Punchline)

**Formula**:
```
Single sentence opener.

4-sentence paragraph (setup).

Single sentence conclusion #1.
Single sentence conclusion #2 (emotional impact).
```

**When to use**: Emphasis, strong opinions, memorable endings

**Example (from Cole)**:
```
Nobody learns hard lessons without failure.

When we let someone down, we learn why. When we fall short, we find our growth edge. When we crumble under pressure, we discover our weaknesses. Those who reach their goals see defeats as opportunities, not punishments.

Unfortunately, that doesn't make learning less painful.

There are some lessons you can't learn without falling down and getting back up.
```

### 1/1/1 (Staccato Emphasis)

**Formula**:
```
Single strong statement.
Another building statement.
Another reinforcing statement.
```

**When to use**: Building intensity, emphasizing duration/scale, creating rhythm

**Example (from Cole)**:
```
I did this for 2 years.

Two. Years.

Not 3 days.
Not a few weeks.

Two entire years. [then decrescendo with longer paragraph]
```

## Main Point Formatting

### Bolded Statements (NOT Lists)

**Instead of**:
```
Main Point 1
Main Point 2
Main Point 3
```

**Use**:
```
**First, you are being "too productive" when input becomes disproportionate to output.**

[Explanation paragraph]

**The second example of being "too productive" is when productivity has a disproportionate impact on quality of life.**

[Explanation paragraph]
```

**Why**: Feels like direct conversation, not a checklist

### Short/Long/Long/Short Rhythm

**Pattern**: Alternate paragraph lengths
- Never 3+ long paragraphs in a row
- Follow long paragraph with single sentence "resolution"
- Mix internal rhythm (one paragraph = short sentences, next = one long sentence)

**Example**:
```
Anyone can make goals—few learn discipline to achieve them. [SHORT]

I grew up watching my dad set the coffee timer every night, wake at 5:30, gym by 6:00, knocking on my door by 7:00, hospital by 8:00. My dad is a spine surgeon. [LONG but many short sentences]

My mom managed teaching, violin lessons, gymnastics, chess club, dinner by 5 p.m., homework by 7 p.m. [LONG, one winding sentence]

Our house operated like a retreat with my mother's thumb on a stopwatch. [SHORT]
```

### Repetition for Advancement

**Use when**: Providing multiple examples, showing progression

**Pattern**:
```
Every single moment of every single day, you are "practicing" something.

If you don't floss, you're practicing not-flossing.
If you eat quinoa instead of Frosted Flakes, you're practicing eating for fuel.
If you yell at your partner, you're practicing lack of self-control.
If you watch TV instead of writing, you're practicing postponing your dream.

[Then longer paragraph synthesizing]
```

### Bold 1/2 Sentences (Signposting)

**Use when**: Moving through time periods, different topics, or story chapters

**Example**:
```
**When I started my gaming blog as a teenager**, I wrote every single night before bed...

**When I quit gaming and started bodybuilding**, I applied this same mentality...

**When I stopped bodybuilding and started writing**, I did it again...
```

**Why**: Signals topic shifts, keeps reader oriented

## Language Rules

### 1. Say It in Fewer Words

- If you can say it in 5 sentences, say it in 3
- If you can say it in 3, try 2
- Delete anything unnecessary

### 2. Write How You Speak

- Record yourself talking, transcribe
- Use natural rhythm, not "professional" voice
- Authentic > polished

### 3. Avoid Long Sentences

- Unless stylistic (counterbalancing short sentences)
- Winding thoughts = confusing reading
- Readers' eyes fly across the page

### 4. Alternate Sentence Length

**Rhythm problem signs**:
- All sentences same length
- All paragraphs same size

**Fix**:
- Short after long
- Long after short
- Really long after really short

### 5. Write Confidently

**Avoid**:
- "I think maybe..."
- "In my opinion possibly..."
- Hedging everything

**Use**:
- Declarative statements
- Take a stance
- Force readers to decide: "I strongly agree" or "I strongly disagree"
- Either beats "Meh"

## Conclusion Options

### The Cliff (Just End)

**Pattern**: Last main point IS the climax, just stop

**When to use**: 800-1200 word articles, clear main points

**Why it works**: Readers don't need conclusions online, they need the information delivered fast

### Forward Momentum

**Pattern**:
```
[Current state or limitation]

Next up: [What's coming]

[Optional: Open question or invitation]
```

### The Resolution

**Pattern**: One paragraph or single sentence wrapping up

**Example**:
```
This mental model shift means you stop chasing LLM improvements and start building reliable pipelines.

If you're building RAG systems, what evaluation approaches are you using?
```

## Visual Formatting Rules

### Never Do This:

❌ Long opening paragraph (7+ sentences)
❌ Three or more long paragraphs in a row
❌ Bullet lists for prose (use natural sentences)
❌ Excessive bolding (trust your words)

### Always Do This:

✅ Alternate paragraph lengths
✅ Use white space generously
✅ Bold statements, not lists
✅ Single sentences for emphasis
✅ Short after long, long after short

## Integration with Ricardo's Voice

### Apply Cole Structure, Keep Ricardo Authenticity

**Cole rhythm**:
```
This project started with "Vibes-Based Development."

I'd write a prompt, run it, think "good enough." That works for exploration. 
But trustworthy outputs for coaches? You need evaluation from day one.

You cannot optimize what you cannot measure.
```

**Ricardo details**:
- Specific metrics ("99.4% faithfulness")
- Tool names (ChromaDB, Claude Haiku)
- Show the bug ("Home/Away swap")
- Honest constraints ("I had API credits to burn")

### The Formula

1. **Structure** (Cole): 1/3/1, 1/5/1, 1/4/1/1 rhythms
2. **Content** (Ricardo): Technical depth, real metrics, honest process
3. **Voice** (Both): Conversational, confident, authentic

**Result**: Posts that are easy to read (Cole) AND technically credible (Ricardo)

## Quick Reference

**Opening**: 1/3/1 (default) or 1/5/1 (more context)
**Main Points**: Bolded statements + alternating lengths
**Conclusion**: The Cliff (just end) or Forward Momentum
**Rhythm**: Short/Long/Long/Short throughout
**Emphasis**: Single sentences, 1/1/1 staccato
**Signposting**: Bold 1/2 sentences for topic shifts
